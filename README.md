# Transporte HEURO

Aplicativo móvel para solicitação e organização dos transportes de pacientes do HEURO.

## Etapa 1

Esta versão contém:

- tela de login demonstrativa;
- identificação do usuário e do perfil;
- painel do solicitante;
- painel do setor de transporte;
- painel do administrador;
- cadastro visual das frotas:
  - Frota 1 — UTI;
  - Frota 2 — Básica;
  - Frota 3 — Básica;
- estrutura inicial de PWA para instalação no celular.

## Acesso de demonstração

- Usuário: qualquer nome;
- Senha: `1234`;
- Perfil: selecionar Solicitante, Transporte ou Administrador.

## Atenção

Esta etapa ainda não utiliza banco de dados real e não deve ser usada com dados reais de pacientes. O login é apenas demonstrativo.

## Próxima etapa

Desenvolvimento da tela de nova solicitação de transporte, com paciente, origem, destino, data, horário, prioridade, condição clínica e revisão antes do envio.
